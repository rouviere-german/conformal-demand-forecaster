# Claims and evidence

Every claim in the README maps to a test, a bench script or a CI job. `scripts/check_baseline.py`
fails if a backticked reference below points at a file, test function or CI job that does not
exist. Local commands run offline; rows marked **CI** are verified only in GitHub Actions.

## The conformal layer

| # | Claim | Evidence | Reproduce |
|---|---|---|---|
| 1 | Split-conformal intervals achieve their finite-sample coverage bracket: over 500 independent exchangeable splits with 200 calibration points, measured coverage lies inside `[1-alpha, 1-alpha + 1/(n+1)]` within binomial tolerance at both 80% and 95%. | `bench/bench_conformal.py`, `.github/workflows/ci.yml#bench` | `uv run python bench/bench_conformal.py --check` |
| 2 | The conformal quantile is the `ceil((n+1)(1-alpha))`-th smallest score, is monotone in alpha, is shift-equivariant, and saturates (reporting it) when the rank leaves the available scores. | `tests/unit/test_cqr.py::test_conformal_quantile_is_an_order_statistic`, `tests/unit/test_cqr.py::test_conformal_quantile_is_monotone_in_alpha`, `tests/unit/test_cqr.py::test_conformal_quantile_is_shift_equivariant`, `tests/unit/test_cqr.py::test_quantile_reports_saturation_when_calibration_is_exhausted` | `uv run python tasks.py test` |
| 3 | A CQR score is non-positive exactly when the raw band already contains the target, and calibrating on a sample covers at least the nominal share of it. | `tests/unit/test_cqr.py::test_cqr_score_sign_matches_containment`, `tests/unit/test_cqr.py::test_conformalized_band_covers_at_least_the_nominal_share_in_sample` | same |
| 4 | Mondrian (segment x horizon) calibration closes the per-segment coverage gap that a pooled band leaves: 0.0082 against 0.0249 on the 200-series backtest, and 0.022 against 0.078 in isolation. | `bench/bench_backtest.py`, `bench/bench_conformal.py`, `tests/unit/test_cqr.py::test_intervals_widen_per_group_and_stay_non_negative` | `uv run python bench/bench_backtest.py --check` |
| 5 | Groups with too few scores fall back to the pooled scores and say so, rather than serving a quantile from three points. | `tests/unit/test_cqr.py::test_small_groups_fall_back_to_the_pooled_scores` | `uv run python tasks.py test` |
| 6 | ACI's long-run coverage bound holds for adversarial error sequences that respect the recursion's premise, and alpha stays inside `[-gamma, 1+gamma]` for every sequence. | `tests/unit/test_aci.py::test_long_run_error_respects_the_gibbs_candes_bound`, `tests/unit/test_aci.py::test_alpha_stays_inside_the_clipping_range` | same |
| 7 | Where the bound's premise fails in this implementation — saturation at the widest observed score — the realized error can exceed it, and the affected rows are flagged rather than hidden. | `tests/unit/test_aci.py::test_the_bound_needs_its_premise_and_saturation_can_break_it`, `docs/adr/0003-adaptive-conformal-inference.md` | same |

| 9 | ACI buys coverage by widening, and the cost is reported: about 1.4x (80%) and 1.7x (95%) the frozen width after the shift. | `bench/bench_shift.py` | same |
| 10 | The shipped `aci_gamma = 0.08` comes from a measured trade-off, not a guess. | `bench/bench_shift.py`, `docs/adr/0003-adaptive-conformal-inference.md` | `uv run python bench/bench_shift.py --sweep` |
